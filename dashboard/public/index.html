How this warehouse is organised (optional)

This is a fact constellation, also called a galaxy: four fact tables share seven dimension tables. It is the Coursework 4 design. An earlier single-star model is kept in the repository under archive/star_v1 and is not what this page shows.

Where the numbers come from

The same synthetic CSV files can be loaded on a laptop with Python and SQLite (coursework4/build_warehouse.py) or into PostgreSQL (supabase/migrations). This page reads the hosted PostgreSQL copy through one read-only function, public.rockshell_dashboard(). The browser never sees the database key.
