Tables and row counts

Why a star schema

  • Every report is one join away from the fact table, so it is simple and fast.
  • Project, supplier, material, employee, client, cost category and date are shared across all measures.
  • Changes to project managers and employee roles are kept as history (SCD Type 2).
  • Budget and actual cost sit in the same table, marked by a scenario column.
  • An "unknown" row (key 0) in each dimension means no fact row is lost in a join.
